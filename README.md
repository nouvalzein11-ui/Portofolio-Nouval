# Portofolio-Nouval

Source situs portofolio Mohammad Nouval Zein: https://nouvalzein.netlify.app

- `dashboards/`: dashboard live (data dummy) yang ditautkan dari portofolio
  - `monitoring-kpi-sales.html`: Monitoring KPI Sales Travel Connectivity
  - `revenue-customer.html`: Laporan Revenue & Customer
- Dashboard live dan dashboard HTML lain tampil di section Dashboard gallery (`SHOTS` di `script.js`); klik membuka dashboard live

Situs statis, tanpa build step. Netlify: publish directory = root (`.`).
